# 폰트 두는 곳

여기에 폰트 파일(.ttf / .otf)을 올리면 **영상이 자동으로 그 폰트를 씁니다.**
올리지 않으면 서버에 기본 설치된 나눔 폰트로 만들어집니다.

## 지금 기다리는 파일 (KoPub 월드체)

| 파일 이름 | 쓰는 곳 |
|---|---|
| `KoPubWorldDotumBold.ttf` | 자막 · 금액 숫자 |
| `KoPubWorldDotumMedium.ttf` | 인물 이름표 · 작은 라벨 |
| `KoPubWorldDotumLight.ttf` | 설명 보조 글자 |
| `KoPubWorldBatangBold.ttf` | 판결 · 제목 (바탕체) |

- 파일 이름의 **띄어쓰기와 대소문자는 상관없습니다.**
  `KoPubWorld Dotum Bold.ttf` 처럼 띄어 써도 똑같이 인식합니다.
- 네 개를 다 올리지 않아도 됩니다. 올린 것만 쓰고 나머지는 나눔으로 채웁니다.
