# assets/ — 그림과 소리

대본에 적힌 **에셋 코드**(예: `funeral_reception`)를 실제 파일로 바꾸는 규칙이 여기 있다.
기계가 읽는 연결표는 [`manifest.json`](manifest.json) 이다.

---

## 코드 → 파일 규칙

| 종류 | 대본에 적히는 코드 | 실제 파일 |
|---|---|---|
| 인물 | `F50A` + `bust_sad` | `assets/char/F50A/bust_sad.png` |
| 배경 | `funeral_reception` | `assets/bg/funeral_reception.jpg` |
| 음악 | `hook` | `assets/bgm/hook.mp3` |
| 앰비언스 | `amb_hospital` | `assets/amb/hospital.mp3` |
| 효과음 | `sfx_gavel` | `assets/sfx/gavel.mp3` |

⚠️ **앰비언스와 효과음만 접두사(`amb_` `sfx_`)를 뗀다.** 대본 안에서 종류를 구분하려고 붙인 것이라
파일 이름에는 들어가지 않는다.

⚠️ **파일 이름은 전부 영문이다.** 한글 파일명은 도구를 거치며 깨진다.

## 캐릭터 시트 규격 (실측 검증 완료)

| 항목 | 값 | 근거 |
|---|---|---|
| 배치 | 3열 × 6행 = 18칸 | |
| 격자선 | 검은색 3px | 잘라낼 때 기준선 |
| 배경 | **크로마 그린 `#00B140`** | 실측 오차 5 이내로 균일 → 배경 제거 정확도 확보됨 |
| 의상 | 남색 상의 + 검정 하의 | **회색 금지** — 배경과 구분이 안 된다 |
| 그림자 | **금지** | 반투명 그림자는 제거가 불가능하다 |
| 18번 칸 | **빈 칸으로 지시** | 무료 등급 워터마크가 여기 떨어진다 |
| 해상도 | 실측 720×1456 → 셀 240px | 부족하므로 **4배 업스케일 필수** |

### 후처리 순서 (1회성)

```
시트 생성 → 3열 6행 슬라이싱 (격자선 4px 안쪽 트림)
  → 크로마키 배경 제거 → **스티커 테두리 + 그림자** → 4배 업스케일 → 커밋
```

### 스티커 테두리 — 잡지에서 오려 붙인 느낌

인물을 배경 위에 그냥 얹으면 '합성한 티'가 난다. 세 겹으로 만들어 이를 없앤다.

| 겹 | 무엇 | 왜 |
|---|---|---|
| 1 | **그림자** | 테두리를 흐리게 해 아래로 조금 내려 깐다. 인물이 배경에서 **떠오른다** |
| 2 | **흰 테두리** | 두께는 인물 높이의 **2.8%**. 가장자리를 **일부러 불규칙하게** 만든다 |
| 3 | 인물 | 맨 위 |

가장자리를 불규칙하게 하는 이유: 매끈한 곡선은 **기계로 오린 티**가 난다.
부드럽게 번지게 한 뒤 잡음을 섞어 다시 잘라내면 손으로 오린 느낌이 난다.

두께를 잘못 잡으면 — **얇으면** 블러 배경에 묻혀 테두리가 있으나 마나이고,
**두꺼우면** 유치해진다. 2.8%가 그 사이다.

**조절하는 법**

```
python3 src/assets_gen.py sheet assets/sheets/F50A.png F50A --outline 0.035
python3 src/assets_gen.py sheet assets/sheets/F50A.png F50A --smooth      # 매끈하게
python3 src/assets_gen.py sheet assets/sheets/F50A.png F50A --no-shadow   # 그림자 끄기
```

## 음악 8트랙 — 미리 만들어 재사용한다

**회차마다 생성하지 않는다.** 같은 프롬프트를 써도 결과가 매번 다르고, 생성 클립을 여러 번
다듬는 편집이 지원되지 않는다. 회차마다 만들면 톤이 튀어 시리즈물에서 치명적이다.
고정하면 음악이 **채널 정체성**이 된다.

| 코드 | 쓰는 곳 | 분위기 |
|---|---|---|
| `hook` | 도입 훅 | 불안, 낮은 현악 |
| `past` | 1막 회상·헌신 | 따뜻하고 애잔한 피아노 |
| `care` | 간병 장면 | 느리고 조용한, 거의 정적 |
| `reveal` | 2막 반전 | 긴장 상승, 심장박동 리듬 |
| `conflict` | 3막 갈등 | 강한 타악, 불협 |
| `court` | 4막 법정 | 무겁고 절제된 긴장 |
| `verdict` | 판결 낭독 | 해소, 상승하는 현악 |
| `outro` | 5막 여운 | 잔잔한 피아노 단독 |

- 생성 모델은 30초 클립을 만든다. **이어붙이기 + 교차 페이드**로 구간 길이를 맞춘다
- ⚠️ **생성 프롬프트와 날짜를 반드시 기록해 둔다.** 2026년 3월 인디 아티스트들이 학습 데이터
  문제로 소송을 제기했다. "라이선스됨"이 "다툼 없음"을 뜻하지는 않는다

## 정보 그래픽 4종 — 파일이 아니라 코드가 그린다

SVG로 즉석에서 그리므로 **에셋 파일이 필요 없다. 비용 0원.**

| 그래픽 | 왜 필요한가 |
|---|---|
| **타임라인** | 판결극장의 반전은 전부 시간 순서다. "재혼 11개월 전"이 말로만 지나가면 충격이 전달되지 않는다 |
| **가족 관계도** | 상속 사건은 관계 파악이 전제다. 도표 1장이 5분 설명을 대체한다 |
| **인물 네임태그** | **고정 배우 7명을 회차마다 다른 역으로 쓰므로 필수다.** 없으면 누가 누군지 끝까지 모른다 |
| **금액 강조** | 숫자는 귀로 들어오지 않는다. 큰 글씨로 화면에 박는다 |
