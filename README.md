# 판결극장 (Verdict Theater)

> 실제 법원 판결을 재구성한 가족 드라마. 유튜브 롱폼 12분 + 쇼츠 3편 자동 제작 파이프라인.
>
> 모든 결정사항은 [`CLAUDE.md`](CLAUDE.md) 에 있다. 착수 절차는 [`STARTGUIDE.md`](STARTGUIDE.md).

---

## 손님이 하는 일은 버튼 누르기뿐이다

```
0. 에셋 만들기   캐릭터·배경·소리          ← 처음 한 번만
1. 판례 수집     법제처에서 받아 기계 선정   ← 주 1회 자동
2. 대본 만들기   소재 심사 + 12분 대본 + 쇼츠
3. 영상 만들기   나레이션 → 렌더 → 유튜브 비공개 업로드
        ↓
   아이폰 유튜브 앱에서 검수 (비공개 영상은 본인만 보임)
        ↓
4. 공개하기      롱폼 공개 → +1/+2/+4일에 쇼츠 1·2·3번
5. 성과 보기     조회수·지속률·KPI 점검     ← 주 1회 자동
6. 관리자 페이지 배포                       ← 처음 한 번만
```

**관리자 페이지**([`admin/`](admin/))를 쓰면 위 버튼을 한 화면에서 누르고,
**12분 대본을 사람이 읽는 모양으로** 검수할 수 있다.

## 설계에서 특히 신경 쓴 것

**글은 Claude, 그림과 소리는 Gemini.** 지침서 0번이 "대본 생성 프롬프트가 이 사업의 유일한
핵심 자산"이라고 못 박는다. 이 사업은 대본 품질이 전부다. 긴 한국어 감정 서사와 절제된 대사는
Claude 쪽이 낫고, 그림과 목소리는 Claude 가 못 만든다. 그래서 나눴다.
글·소재 심사·채점·그림·목소리 **전부 Gemini 하나로** 간다.
(2026-08-23 운영자 지시로 Claude API 를 껐다. `tools/no_claude_test.py` 가 매번 다시 새지 않는지 검사한다.)

**모델 이름을 코드에 박지 않는다.** 모델명은 자주 바뀐다. 박아두면 어느 날 갑자기
파이프라인이 죽는데 운영자는 원인을 알 수 없다. 실행할 때마다 API에 "지금 쓸 수 있는 모델"을
물어서 고른다. Claude 쪽도 같은 방식이다.

**대본을 한 번에 뽑지 않는다.** 컷 113개는 JSON 으로 3만 토큰이 넘는다. 출력 한도에 걸리면
중간에서 잘린 JSON 이 오고 통째로 버려야 한다. **설계 한 번 → 막별 여섯 번**으로 나눈다.
덤으로 품질도 오른다.

**기계가 먼저 검사한다.** 대본은 사람 손을 안 거치고 렌더링에 들어간다. 코드가 하나만
틀려도 12분 렌더링이 통째로 실패한다. 눈으로 보는 검수는 반드시 놓친다.

**에셋이 없어도 끝까지 돌린다.** 캐릭터·배경이 없으면 실루엣으로 대체해 파이프라인이
도는지 먼저 확인한다. **파이프라인이 도는 걸 확인해야 에셋에 돈을 쓸 수 있다.**

**비용 상한을 코드가 강제한다.** 버그로 무한 루프가 돌면 과금이 폭발한다.
한 실행에서 쓸 수 있는 호출 수를 미리 정하고 넘으면 멈춘다.

## 절대 하면 안 되는 것

| 금지 | 이유 |
|---|---|
| **완성 영상(MP4)을 커밋** | 편당 200~500MB. 지워도 이력에 영구히 남는다. `.gitignore` 가 막고, `produce.yml` 이 마지막에 다시 확인한다 |
| **API 키를 파일로 저장** | 즉시 유출된다. Secrets 에만 넣는다 |
| **댓글에서 개별 법률 상담에 답변** | 변호사법 제109조 제1호 위반 소지 |
| **판사 실명 노출** | 판결문에 실명이 그대로 나온다. 검증기가 자동으로 잡는다 |
| **가사사건(이혼·재산분할·양육권) 소재 사용** | 가정법원 판결문은 공개되지 않는다 |
| **쇼츠 3편 같은 날 업로드** | 조각내기 신호가 명확해져 노출이 죽는다 |

## 아직 검증되지 않은 것

| 항목 | 상태 |
|---|---|
| **대본 재현성** | **최대 리스크.** 반전이 강한 판례 1건만 확인했다. 평범한 판례로 한 번 더 해봐야 한다 |
| 실제 모델이 뽑은 대본 품질 | `GEMINI_API_KEY` 등록 후 확인 |
| 캐릭터 시트 생성 품질 | 얼굴이 18칸에서 일관되는지 |
| 유튜브 업로드 | 토큰 등록 후 확인 |

> ⚠️ 유튜브 API 는 **댓글 고정**과 **AI 생성 콘텐츠 표시**를 지원하지 않는다.
> 댓글은 자동 등록되지만 고정은 앱에서 직접 해야 하고, AI 표시는 스튜디오에서 켜야 한다.
> 설명란에는 이미 적히므로 정책 방어는 된다.
