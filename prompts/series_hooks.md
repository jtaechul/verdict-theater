# 16화 시리즈의 후킹·제목만 다시 뽑는다 (이야기는 안 건드린다)

## 이 파일 사용법 (운영자용 메모 — 모델에게 보내지 않는다)

`python3 src/hooks.py S001` 가 이 파일을 읽는다.
아래 PROMPT 표시 **사이만** 모델에게 간다.
`{{SERIES_JSON}}` 한 자리를 hooks.py 가 채운다 — 화별 제목·줄거리·대사 자막만
추려서 넣는다 (컷 프롬프트는 안 보낸다. 값이 아까우므로).

이미 만든 대본을 **다시 사지 않고** 맨 위 한 줄과 유튜브 제목만 갈아 끼우는
싸구려 수리다. 대사·장면·인물은 한 글자도 안 바뀐다.

아래는 이미 완성된 16화짜리 세로 쇼츠 시리즈다. **이야기는 이미 다 정해졌다.**
너는 **화면 맨 위에 붙는 후킹 한 줄(`hook`)** 과 **유튜브 제목(`yt_title`)** 만
16화 전부 새로 뽑는다. 대사·장면·인물은 손대지 않는다.

## 왜 다시 뽑는가

지금 붙어 있는 것들이 이렇다 — `집을 나가는 남편` `이혼 소송 기각` `앙심을 품다`.
이건 **목차**지 후킹이 아니다. 아무 일도 안 일어난 것처럼 보인다.
운영자 지시: **"자꾸 점잔 빼지 말고 선비처럼. 신경을 자극하고 관심을 유도하고,
속이지 않는 범위 내에서 최대한 과장되고 사람들이 유인되게끔."**

## 지켜야 할 여섯 가지

1. **거짓말은 절대 금지.** 아래 대본에 없는 일은 한 글자도 안 쓴다.
   과장은 하되 **속이지 않는다.** (죽지 않은 사람을 죽었다고 쓰면 끝이다)
2. **숫자를 넣는다.** `15억` `0원` `십 원 한 장` `이십 년` — 숫자는 그 자체로 세다.
3. **배신 · 상실 · 뒤집기 중 하나를 반드시 드러낸다.**
4. **결말은 말하지 않는다.** 궁금해야 남는다.
5. **상태가 아니라 사건으로 끝낸다.** 동사로 끝내라.
   `집을 나가는 남편` (상태 ✗) → `남편이 통장을 비우고 집을 나갔다` (사건 ○)
6. **센 대사 한 줄을 따옴표째 써도 좋다.** `"내 돈은 십 원도 못 줘"`

## 쓰면 안 되는 밋밋한 말투

`~에 대하여` · `~의 진실` · `~하는 이유` · `~ 이야기` · `~의 전말` ·
`충격` · `경악` · `소름` (흔해 빠져서 오히려 안 눌린다)

## 예시

| ✗ 이렇게 쓰면 안 된다 | ○ 이렇게 쓴다 |
|---|---|
| 집을 나가는 남편 | 남편이 통장을 비우고 집을 나갔다 |
| 이혼 소송 기각 | 소송은 이겼는데 재산이 사라졌다 |
| 앙심을 품다 | "내 돈은 십 원도 못 줘" |
| 끝없는 빼돌리기 | 15억이 다른 여자 이름으로 넘어갔다 |
| 갑작스러운 죽음 | 그가 죽은 날 통장은 이미 비어 있었다 |
| 상속 재산 분쟁 | 이십 년 며느리 몫은 0원이었다 |

## 길이

- `hook` — **22자 이내.** 화면 맨 위에 30초 내내 붙는다. 길면 잘린다.
- `yt_title` — **40자 이내.** `(n/16)` 과 `#shorts` 는 우리가 붙이니 적지 않는다.

## 이어지게 쓴다

1화는 **아무것도 모르는 사람**이 보는 첫 화다. 가장 세게 뽑는다.
2화부터는 앞 화를 본 사람이 이어 본다 — 앞에서 던진 것이 어떻게 되는지
궁금하게 만든다. 16화는 마지막이므로 **판결**이 궁금하게 만든다.

## 출력 형식

**JSON 하나만** 출력한다. 머리말·설명·코드펜스 없이 `{` 로 시작해 `}` 로 끝난다.
16개를 하나도 빠뜨리지 않는다.

```json
{
  "title": "바람난 남편이 빼돌린 15억",
  "episodes": [
    { "no": 1, "hook": "남편이 통장을 비우고 집을 나갔다", "yt_title": "바람난 남편이 통장을 비우고 집을 나갔습니다" }
  ]
}
```

`title` 은 시리즈 전체 제목이다. 지금 것이 이미 세면 그대로 두고,
밋밋하면 위 규칙대로 다시 뽑는다.
