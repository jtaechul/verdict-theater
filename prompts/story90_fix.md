# 규격 (어긋난 자리를 고칠 때 지킬 것)

- `yt_title` 유튜브 제목. **30~45자를 겨냥한다. 22자보다 짧으면 안 된다.**
  앞 20자 안에 가장 센 것(금액·배신·충격 사실)을 넣는다. 끝말을 세게 맺는다.
  **편 번호를 쓰지 않는다** — "2편" 이 보이면 사람들이 넘긴다.
- `card` 화면 위 두 줄. **각 줄 16자 이내.**
- `series_label` **12자 이내.**
- 한 편은 **6~10컷**, 말하는 글자 수를 다 더해 **225자 이내**.
  넘으면 60초를 넘고, 60초를 넘으면 쇼츠 피드가 안 태운다.
- 화자(`turns` 의 첫 칸)는 그 대본의 사람 목록에 있는 이름 또는 `나레이션`.
  **법원·재판부·판사는 화자로 쓰지 않는다** — 판결은 나레이션이 전한다.
- 사람을 더 세우려면 `people` 에 `{"장남": {"age": "30대", "sex": "남"}}`
  꼴로 적는다. 기본 다섯(아내·남편·내연녀·딸·변호사) 말고 **4명까지**.
- **나레이션은 주어를 밝힌다.** `끝내 불륜의 대가를 치렀습니다.` 처럼 누가
  그랬는지 빠지면 안 된다 → `내연녀는 결국 불륜의 대가를 치렀습니다.`
  (`…소리였습니다` 처럼 무엇인지를 밝히는 문장은 주어가 없어도 된다)
- `say` 연기 지시는 **감정을 속으로 눌러 담는 말**로 적는다.
  쓰지 않는 말: 목소리를 높여 · 터져 나오듯 · 소리치듯 · 내지르듯 ·
  이를 악물고 · 서슬 퍼렇게 · 몰아붙이듯 · 날카롭게 · 격하게 · 세게
- `scene` 화면 묘사는 영어 한 문장. 글자가 나올 물건(bank statement,
  letterhead, business card, receipt, id card, newspaper)을 부르지 않는다.

# 내놓을 것

**고친 자리만** 담은 JSON 하나. 아래 꼴을 그대로 지킨다.
안 고친 것은 넣지 마라.

```json
{
  "parts": [ {"no": 2, "yt_title": "고친 제목"} ],
  "cuts":  [ {"n": 13, "turns": [["나레이션", "고친 대사"]], "who": [], "say": ["고친 지시"]} ],
  "people": {"장남": {"age": "30대", "sex": "남"}},
  "title": "...", "series_label": "...", "hook": "..."
}
```

- `parts` 는 고친 편만, `no` 로 어느 편인지 밝힌다.
- `cuts` 는 고친 컷만, `n` 으로 어느 컷인지 밝힌다. 그 컷 안에서도 고친 칸만 적는다.
- `people` · `title` · `series_label` · `hook` 은 고쳤을 때만 적는다.
- 설명·인사말을 붙이지 마라. JSON 만 내놓는다.
