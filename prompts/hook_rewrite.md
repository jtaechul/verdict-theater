이미 완성된 12분 드라마 대본의 **맨 앞 22초(도입 훅)만** 다시 쓴다.
나머지 막은 손대지 않는다. 훅 다섯 컷의 **대사 글자만** 새로 쓴다.

## 왜 다시 쓰는가

운영자 지적: *"오프닝 훅 부분은 대사가 지금 전혀 무슨 내용인지 파악도 안 된다."*

실제로 이런 훅이 나갔다. 무엇이 잘못됐는지 그대로 적는다 — **같은 잘못을 되풀이하지 마라.**

| 나갔던 대사 | 무엇이 잘못됐나 |
|---|---|
| "저한테 다 맡기고 가셨어요." | **저**가 누구인지, **누가** 갔는지 하나도 모른다 |
| "이십 년을 혼인신고한 아내가, 그 자리에 서 있었습니다." | 말이 안 되는 문장이다. **그 자리**가 어디인지도 모른다 |
| "조문객들은 선희 씨를 비켜 지나갔습니다." | **선희**가 누구인지 소개된 적이 없다 |
| "오늘은 그냥 돌아가세요." | **누가 누구에게** 하는 말인지 모른다 |
| "그 사람은 오래전에 집을 나가 있었습니다. 그런데 왜, 저 사람이 서 있을까요." | **그 사람**과 **저 사람**이 같은 사람인지 다른 사람인지 모른다 |

한마디로 **가리키는 말만 있고 가리키는 대상이 없다.**
보는 사람은 50~60대이고 휴대전화로 한 번 본다. 되감아 보지 않는다.

## 반드시 지킬 것

1. **사람은 이름이 아니라 관계로 부른다.**
   `선희 씨` (✗) → `이십 년을 같이 산 아내` (○)
   이름을 쓰려면 관계를 먼저 붙인 **뒤에만** 쓴다.
2. **그 사람 · 저 사람 · 그 자리 · 저기 · 거기** 같은 **가리키는 말을 쓰지 않는다.**
   가리킬 것이 있으면 그 자리에 정체를 그대로 적는다.
3. **다섯 컷을 다 보고 나면 세 가지가 남아야 한다.**
   ① 누가 (관계로) ② 어디서 (장례식장·법정 등) ③ 무엇을 다투는가
   셋 중 하나라도 안 나오면 다시 써라.
4. **한 문장에 한 가지만 말한다.** 쉼표로 두 문장을 이어 붙이지 않는다.
5. **첫 컷은 3.0초 이내, 인물의 대사로 시작한다.** 나레이션으로 시작하지 않는다.
6. **금액과 결말은 밝히지 않는다.** 마지막 컷은 답이 없는 질문으로 끝난다.
7. **주인공이 반드시 말한다.**
   주인공(아내·남편 같은 다툼 당사자)이 훅에서 한 마디도 안 하면 보는 사람은
   누구 이야기인지 모른 채 22초를 보낸다. 실제로 그렇게 나갔다 — 말한 사람이
   **동거인과 시동생**이었고 주인공인 아내는 한 마디도 안 했다.
   필요하면 `speaker` 를 바꿔라. **단 그 컷의 `화면에_있는_사람` 안에서만** 고른다
   (화면에 없는 사람이 말하면 그림과 소리가 따로 논다).
8. **뒤에 이어지는 본편의 문장을 되풀이하지 마라.**
   실제로 훅 마지막 줄과 본편 첫 줄이 거의 같은 문장이었다.
     훅   "그 사람은 오래전에 집을 나가 있었습니다."
     본편 "그 사람은 이미 오래전에 집을 나가 있었습니다."
   같은 말을 두 번 들으면 보는 사람은 되감긴 줄 안다. **본편으로 자연스럽게
   넘어가되 다른 말로** 쓴다. 훅은 질문을 남기고, 본편이 답을 시작한다.
9. `sec`(길이)·`bg`(배경)·`chars`·`amb` 는 **원래 값을 그대로 둔다.**
   바꿀 수 있는 것은 `text` 와 (필요할 때만) `speaker` 둘뿐이다.
10. 한 컷의 대사는 그 `sec` 길이에 어울리게 쓴다. 길면 컷이 늘어나 늘어진다.

## 낼 것

JSON 하나만 낸다. 다른 말은 붙이지 않는다.
컷 개수와 `id` 는 지금 훅과 **똑같이** 유지한다.

```json
{ "cuts": [
    { "id": "H01", "text": "새 대사", "speaker": "v_F50A" },
    { "id": "H02", "text": "..." }
] }
```

`speaker` 는 **바꿀 때만** 적는다. 그대로 둘 컷에는 쓰지 않는다.
