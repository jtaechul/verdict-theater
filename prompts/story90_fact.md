## 왜 이것이 필요한가 (운영자용 — 모델에게 안 보냄)

2026-09-05 손님: **"상간녀가 위자료를 더 높여 불렀다. 이거는 반대가 되는 거
아니야? 이런 부분들은 왜 사전에 그 검증을 못하는 거지?"**

맞는 지적이었다. S91 컷18 이 이렇게 나왔다 —

> 여자는 사생활 침해라며 **위자료를 더 올려 불렀습니다.**

판결문의 실제는 정반대다. 위자료 3,000만 원은 **아내가 상간녀에게** 받는 돈이고,
상간녀가 한 것은 **반소(맞소송)로 3,000만 원을 청구**한 것이다(50만 원만 인용).

그때까지 대본 검사는 **규격만** 봤다 — 편 수, 글자 수, 컷 수, 화자, 주어.
"이 말이 판결문과 맞는가" 를 보는 검사는 **한 개도 없었다.** 판결문은 저장돼
있는데 대본을 지은 뒤 아무도 다시 안 봤다. 이 프롬프트가 그 자리를 메운다.

⚠️ **각색을 트집 잡으면 안 된다.** 이 채널은 판결문을 드라마로 만든다. 대사와
   장면은 지어낸 것이 당연하다. 잡아야 하는 것은 **사실이 뒤집힌 것**뿐이다.

판결문과 그것으로 만든 쇼츠 대본을 준다. 대본이 **판결문과 어긋나는 줄**만
찾아라. 그 밖의 것은 아무것도 하지 마라.

# 무엇을 잡는가 (이것만)

1. **방향이 뒤집힌 것** — 누가 누구에게 청구했는지, 누가 이겼는지, 누가 돈을
   내는지가 판결문과 반대인 것
2. **금액·날짜·횟수가 틀린 것** — 판결문에 없는 숫자를 지어냈거나 다른 숫자로
   바꾼 것
3. **법률 관계를 잘못 부른 것** — 반소(맞소송)를 "위자료를 올려 불렀다" 처럼
   딴 것으로 부르거나, 청구한 쪽과 인정된 쪽을 섞은 것
4. **물건·수단이 바뀐 것** — 판결문의 녹음장치를 "블랙박스" 로 바꾸는 것처럼
   이야기의 핵심 물건이 딴 것이 된 경우
5. **판결문에 없는 사실을 단정한 것** — 있었는지 알 수 없는 일을 있었다고 쓴 것

# 무엇을 잡지 않는가 (중요)

- **지어낸 대사와 장면** — 이 채널은 드라마다. 판결문에 없는 대사·표정·날씨·
  방 안 모습은 **당연히 지어낸 것이고 잘못이 아니다.**
- **말투·순서·생략** — 90초에 맞추려고 줄이거나 순서를 바꾼 것
- **사람 이름을 아내·남편·내연녀로 바꾼 것** (우리 규칙이다)
- **판결문에 적힌 것을 부드럽게 돌려 말한 것**

의심스러우면 **잡지 마라.** 틀린 것만 확실할 때 적는다.

# 돌려줄 것 (JSON 하나만)

```json
{
  "wrong": [
    {
      "n": 18,
      "무엇이틀렸나": "상간녀가 위자료를 올려 불렀다고 썼다",
      "판결문은": "상간녀가 반소로 3,000만 원을 청구했고 50만 원만 인정됐다",
      "이렇게": "여자는 오히려 불법 녹음이라며 똑같이 삼천만 원을 요구했습니다."
    }
  ]
}
```

- `n` 은 컷 번호다.
- `이렇게` 는 **그 자리에 그대로 넣을 수 있는 한국어 한 줄**로 적어라.
  글자 수는 원래 줄과 비슷하게 (길어지면 편이 60초를 넘는다).
- 어긋난 곳이 없으면 `{"wrong": []}` 만 돌려줘라.
